# Измеритель скорости загрузки

Консольная утилита для измерения скорости скачивания с указанного HTTP(S)-сервера.
По десяти последовательным загрузкам она рассчитывает среднее время запроса,
общий объём полученных данных и скорость скачивания.

## Системные требования

- Python 3.11 или новее;
- установленный [uv](https://docs.astral.sh/uv/);
- доступ к выбранному серверу по HTTP или HTTPS.

Установите зависимости из файла блокировки:

```shell
uv sync --locked
```

## Запуск

```shell
uv run download_speed.py https://proof.ovh.net/files/10Mb.dat
```

Это тестовый файл [OVHcloud](https://proof.ovh.net/files/). За десять загрузок файла
размером 10 МиБ будет передано 100 МиБ. Адрес обязателен. Тайм-аут одной блокирующей
сетевой операции можно изменить:

```shell
uv run download_speed.py https://proof.ovh.net/files/10Mb.dat --timeout 15
```

Во время каждого запроса ход загрузки выводится в stderr. В терминале строка обновляется
не чаще четырёх раз в секунду и показывает полученный объём и среднюю скорость текущего
запроса. Если размер известен, также отображаются полоса и процент. Итоговая сводка в
stdout содержит число запросов, среднее время, общий объём в байтах и скорость в МиБ/с,
где 1 МиБ = 1 048 576 байт. Скорость рассчитывается как суммарный объём, делённый на
суммарное время всех загрузок.

Результат характеризует выбранный сервер, а не предельную пропускную способность
подключения. Замер включает установление соединения, задержки сервера, перенаправления и
промежуточный вывод. Тайм-аут применяется к отдельным блокирующим сетевым операциям и не
ограничивает общую длительность запроса или разрешения имени сервера. Допускается не более
десяти перенаправлений, и только между адресами HTTP(S).

## Проверка проекта

```shell
uv sync --locked
uv run --locked pytest
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked mypy download_speed tests
uv run --locked mypy download_speed.py
```

Те же проверки автоматически выполняются в GitHub Actions при отправке изменений и для
запросов на слияние. Тесты используют только локальные серверы и не загружают публичный
пример.
